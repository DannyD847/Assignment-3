# Assignment-3
Course assignment 3

This folder contains two files, which are task 1 and task 2.

Task 1 -  Defines a function named factorial that takes a number as an argument and calculates its factorial. Returns the calculated factorial. Calls the function with a sample number and prints the output.

Task 2 - Asks the user for a number as input.   Uses the math module to calculate the:
o   Square root of the number
o   Natural logarithm (log base e) of the number
o   Sine of the number (in radians)

Displays the calculated results.
